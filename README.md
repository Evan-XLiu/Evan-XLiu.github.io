## Visitor map

The Showcase visitor column uses the [MapMyVisitors](https://mapmyvisitors.com/)
rotating globe. Its `globe.js` embed ID is configured in
`visitor_map.mapmyvisitors_id` in `_config.yml`.
The globe appears in Showcase and the widget loads across
the site to count visits. Statistics start after activation; past visits
cannot be recovered. Leaving the ID empty disables the external widget and
shows a coming soon message in Showcase.
